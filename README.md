# Global Sales Dashboard

## Overview
This Tableau dashboard analyzes global sales performance, providing insights into:
- Country-wise sales contributions and shipping volumes.
- Quarterly sales trends across regions.
- Top-performing salespersons.
- Most popular products based on revenue and shipping metrics.

## Key Features
- **Interactive Filters**: Slice and dice data by country, product, and time period.
- **Visualizations**:
  - A world map for country-wise sales and volume.
  - A line chart for seasonal trends.
  - A bar chart for top salespersons.
  - A treemap for product performance.

## Tools Used
- **Tableau**: For dashboard creation.
- **Excel**: For dataset cleaning and preparation.

## Dataset
- The dataset includes anonymized sales data with fields like:
  - Country
  - Salesperson
  - Product
  - Date
  - Amount
  - Boxes Shipped
